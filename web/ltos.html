LTOS 0.5, (LiteOS) for the Elf2K, booting from a simulated CompactFlash card in your browser. This is the real kernel, shell and programs, running on an emulated Elf2K based on the RCA 1802 with its serial port, CF card and clock. All the STELLAR apps run on the real STELLAR firmware, and they return back to LTOS when completed or exited from.

Serial terminal

Click the terminal and type. Enter, Backspace, the arrow keys and Ctrl-keys all go through, as from a VT100 on the Elf2K's serial port. Changes to the card stay in this browser. Restore the card puts every file back as it was and starts the demo over.

What is running

The 1802 is the same emulator as the rest of this site. Around it is an Elf2K: a 16550 UART and a DS12887 clock on ports 2 and 3, and a CompactFlash card on the IDE registers, holding an 8 MB FAT16 image. At power-on the BIOS reads the card's boot sector, which loads the LTOS kernel. Everything after that is LTOS: the shell, the FAT code, the programs in /BIN and the STELLAR firmware that the STELLAR apps run on.

The BIOS is not the Elf2K's ROM. That belongs to Spare Time Gizmos, so this page uses a small stand-in written for the web (LTOS/webbios.asm). It provides the seven BIOS calls LTOS uses, at the same addresses, and is checked against the real ROM in the simulator: the same LTOS sessions give exactly the same screens and the same card. There is no ROM monitor, so MON just boots LTOS again.

The clock is set to 10× the Elf2K so the demo is quick. Choose Elf2K to feel the real machine: a program loads in a second or two, and FSCK takes a few minutes.
