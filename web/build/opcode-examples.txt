## 01 02 03 | Set the output port, the input port and the EF source
src: T1 T2
fix: DEFIN 05 is refused: the input port must be 9 to F, so the program stopped with error 08 at the second line. DEFEF 01 named EF line 0. The explanations said port 03 while T2's code said 04. Now it sets the three settings to real values; T2 was the same program and is covered here.
note: These three commands tell a program where its input and output are. Run them first if your hardware is not the Elf2K default of output 4, input C, EF4.
expect: OP~=410901 E=00
CD
01 01 ; Define the output port as 1
02 09 ; Define the input port as 9
03 41 ; EF source = EF4, inverted (active low)
F0 00 00
