Opcode set

Every STELLAR v0.61 opcode. Operand notation: NN immediate byte · MM MM address · X/Y register · Z/D nibble selector · LL label · V VM number. Each row links to itself — e.g. #op-4D.

Click an opcode's description to see worked examples of it, and click again to close them. Each program was run on the V0061.37 firmware, and the results shown are what the machine did. Key the D-lines into the monitor, or try them in the Simulator. Whole multitasking programs are at the end of the page.
