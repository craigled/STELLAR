↻How the hand-off works

Each active VM runs a small number of opcodes — the quantum, counted down in each core's interrupt counter (+$5E of its core block) — then yields. The scheduler (Do_Next_Task, $0080) scans the CIDP for the next VM whose State is $01 (active) and hands it the CPU, updating Current VM# at $2F52. A VM waiting on serial input yields cooperatively instead of blocking the others. When a VM's program ends its State becomes $00 (done) and the scheduler skips it.
