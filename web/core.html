The VM Core

Everything a STELLAR VM knows lives in a 256-byte block of RAM (VM 1 at $3000). The firmware reads and writes it as it interprets each opcode — so this panel is a live window onto that memory. Load a program and step it; cells the last opcode changed light up.

?What you're looking at

Registers

R0–RF

Sixteen general-purpose 16-bit registers. Programs use them for pointers, counters, and operands. (R0 is reserved.)

Accumulators

Acc · MA · DA

The 16-bit working Acc; the Math Accumulator that receives multiply/divide results plus a remainder and sign; and the packed-BCD Decimal Accumulator.

Flags & state

Test · Carry · …

The Test flag drives every branch. Carry means borrow/overflow. Quantum is the multitasking countdown before this VM yields.
